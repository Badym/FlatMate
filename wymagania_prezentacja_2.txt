Endpoint
W kontekście tworzenia oprogramowania endpoint to konkretny punkt
dostępu (adres URL) w aplikacji, do którego wysyła się zapytania, aby pobrać,
zapisać, zmienić lub usunąć dane.
• Klient (np. przeglądarka lub aplikacja mobilna) wysyła żądanie HTTP (np.
GET, POST, PUT, DELETE) do serwera na określony endpoint.
• Każdy endpoint zwraca kod odpowiedzi HTTP wraz z wysyłanymi danymi.
Kod statusu HTTP (HTTP status code) jest kluczową częścią odpowiedzi
serwera. Informuje on aplikację kliencką (np. przeglądarkę, aplikację
mobilną), czy żądanie zakończyło się sukcesem, czy wystąpił błąd i jaka była
jego przyczyna.
Przykłady:
• GET /api/users – pobiera listę wszystkich użytkowników.
• POST /api/invoices – tworzy nową fakturę w systemie.

Aplikacja ma mieć jeden endpoint o nazwie /health, który ma zwrócić plik json ze
statusem aplikacji – czy aplikacja jest uruchomiona.
Zwracany plik json:
{
"status": "ok"
}
Endpoint ten musi także zwracać kod HTTP 200 i być dostępny bez logowania.
